# robust-mt-estimation
This repository contains Python implementations of M-, S-, and MM-estimation methods for robust magnetotelluric impedance estimation under mixed-noise environments.

regression: Regression algorithm file

robust.py、local.py: the code for M-estimation

s_robust.py、s_local.py: the code for S-estimation

mm_robust.py、mm_local.py: the code for MM-estimation

site1: The file with added noise

site2: synthesized clean electromagnetic field data

statistics: The file of statistical data

synthetic_experiments: The code file for the synthesis experiment
